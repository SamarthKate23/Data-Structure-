# Data Structure Case Studies

## Introduction
This repository contains Python programs developed as part of the Data Structures and Algorithms subject. Each case study demonstrates the practical application of data structures and algorithms.

## Objectives
- Understand data structures and algorithms through practical examples.
- Implement programs using Python.
- Execute programs and verify their outputs.
- Learn how to maintain and submit source code using GitHub.

## Programming Language
- Python 3

## Case Studies

### Unit I: E-commerce Product Sorting
Implements Merge Sort using the Divide and Conquer strategy to sort e-commerce products.

### Unit II: Social Network Adjacency Matrix
Represents friendship connections between users using a two-dimensional array (adjacency matrix).

### Unit III: Stack and Queue Using Linked Lists
Implements stack and queue operations using linked lists, including insertion, deletion, and display.

### Unit IV: Dictionary Application Using Hash Tables
Stores and retrieves words and meanings using a hash table and handles collisions using separate chaining.

### Unit V: Graph Algorithms and Huffman Coding
- **GPS Navigation System:** Represents locations and roads as a weighted graph and finds the shortest route using Dijkstra's algorithm.
- **Huffman Coding:** Demonstrates frequency-based encoding and decoding using a Huffman tree.

## How to Run the Programs
1. Open the required Python file in this repository.
2. Copy the code into an online Python compiler, such as Programiz, or run it using Python 3.
3. Execute the program.
4. Enter the required input, if prompted.
5. Compare the output with the expected result.

## Tools Used
- Python 3
- Online Python Compiler
- GitHub

## Conclusion
These case studies demonstrate the practical use of sorting, arrays, linked lists, hashing, graphs, and tree-based algorithms.
